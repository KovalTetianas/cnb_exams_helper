# Поиск ответов к экзаменам ČNB

Личный помощник для подготовки к экзаменам ČNB.

1. Выберите экзамен (Životní pojištění, Penze, Investiční zprostředkovatel, Úvěry).
2. Вставьте в поле скриншот вопроса (Ctrl+V / ⌘V), перетащите картинку, выберите фото — или просто начните печатать текст вопроса.
3. Скриншот показывается крупно, на всю ширину поля. Текст на нём распознаётся (Tesseract, чешский язык)
   прямо в браузере, вопрос ищется в базе, и ниже показывается вопрос со всеми вариантами — правильные отмечены ✓.
4. Варианты ответа выводятся **в том же порядке, что и на скриншоте** (A, B, C, D как на экране), даже если в базе
   они записаны в другом порядке. Если порядок определить надёжно не удалось — показывается порядок из базы с пометкой.
5. Каждая новая вставка/правка текста обновляет результат. Если совпадение неуверенное — ниже список других похожих вопросов.

## Запуск

Это статический сайт без сборки. Локально:

```
python3 -m http.server 8000
```

и откройте http://localhost:8000. Или включите GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

## Состав

- `index.html` — интерфейс
- `matcher.js` — нечёткий поиск вопроса (устойчив к ошибкам OCR, лишнему тексту на скриншоте и неполному вводу)
- `data/*.js` — база вопросов из [KovalTetianas/cnb_exams](https://github.com/KovalTetianas/cnb_exams)
- `vendor/` — Tesseract.js 5.1.1 (Apache-2.0) и чешская языковая модель, чтобы распознавание работало без внешних CDN
